# ror_training

Assignemnt 1 (Ruby on rails):
Note: Learn how to use "devise" gem for authentication

- [ ] Make a table "User" with "email" and an encrypted password field
- [ ] Make a register page with field "email" and "password", and button "Register"
- [ ] When filled in email and password, then click "Register", a record "users" is created in database
- [ ] Make a login page, user can see the login form with 2 fields: "Email" and "Password"  and a "Login" button
- [ ] When fill in the correct email/password created from "register" page, user can access the "Product" page
- [ ] When logged in, user can see "Logout" button
- [ ] When click "Logout", user is logged out and redirected to the login page
- [ ] When access "Product" page without logging in, user is redirected to login page
